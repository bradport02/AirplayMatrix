Troubleshooting

Shutting down fully powers off the Pi. There is no remote wake -- only physical access (unplug/replug power, or a smart plug) can bring it back on.

Restore default settings

Resets the P3 matrix display (power, mode, brightness, colour), the desk-display lyrics/song-details toggles, and TV auto-off timeout back to their defaults, and generates a brand-new random admin password -- shown once, right after, on the login page. You'll be logged out immediately. Wi-Fi and the AirPlay device name are left untouched.
