{{ icon('mic') }} Lyric sync on connect

AirPlay starts the audio before it sends any metadata, so the first song of a session can be several seconds in before its lyrics are even known -- and they can stay out of step for the rest of that track. With this on, the receiver stays silent when you first connect until the metadata and lyrics have arrived, then restarts the track and unmutes, so the song and its lyrics begin together. Only the first track of a session is affected; later track changes are never interrupted. Costs a few seconds of silence at the start. Currently {{ 'on' if display.sync_on_connect else 'off' }}. Off by default.

{{ icon('refresh') }} Track transition

How the display moves from one track to the next. Fade takes the outgoing track out to the background and brings the new one up once its artwork has loaded. Cross-fade dissolves the old artwork and title straight into the new, never passing through an empty screen -- it costs a little more, since both covers are decoded and composited at once for the length of the transition. Currently {{ 'cross-fade' if display.transition_mode == 'crossfade' else 'fade' }}.

{{ icon('sliders') }} Cross-fade time

How long each stage of a cross-fade takes. A track change runs two stages back to back (the title and lyrics fade out, then the artwork dissolves as they fade back in), so the whole transition takes roughly twice this. Only applies in cross-fade mode. Currently {{ '%.1f'|format(display.crossfade_seconds) }}s.

Troubleshooting

Shutting down fully powers off the Pi. There is no remote wake -- only physical access (unplug/replug power, or a smart plug) can bring it back on.

Restore default settings

Resets the P3 matrix display (power, mode, brightness, colour), the EQ meter toggle, the desk-display lyrics/song-details toggles, and TV auto-off timeout back to their defaults, and generates a brand-new random admin password -- shown once, right after, on the login page. You'll be logged out immediately. Wi-Fi and the AirPlay device name are left untouched.
